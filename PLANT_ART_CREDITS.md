# Garden Defense – external plant artwork

These third-party images are downloaded during the GitHub Actions build and packed into the APK. If a source is temporarily unavailable, the game falls back to its bundled vector artwork.

| Game use | Source | Creator | License |
|---|---|---|---|
| Cabbage-pult (cropped from vegetable sheet) | https://opengameart.org/content/2d-vegetables | ScratchIO | CC0 |
| Kernel-pult (cropped from cereal sheet) | https://opengameart.org/content/2d-cereals | ScratchIO | CC0 |
| Melon-pult (cropped from fruit sheet) | https://opengameart.org/content/2d-fruits | ScratchIO | CC0 |

CC0 means these assets are dedicated to the public domain by their creator. The original sheets are kept as source files by the project build script; cropped sprites are produced by the game at startup.
